# EduPrint 数学打印制作 MVP 设计

## 1. 目标与范围

本次仅实现数学线 MVP，覆盖以下页面：

- 数学模板列表页
- AI生成计算题页（规则随机，不接模型）
- 凑十法页
- 破十法页

核心目标：

- 左侧参数配置 + 右侧实时预览
- 支持一次生成多页题目
- 一键打印全部页面
- 先保证流程可用与打印正确，再逐步做视觉精修

不在本次范围：

- 语文模板
- 云端存储/账号体系
- 大模型题目生成
- PDF 导出

## 2. 交互与信息架构

采用单页应用 + 路由分模块：

- `/math`：模板列表
- `/math/ai-calc`：AI生成计算题（规则出题）
- `/math/make-ten`：凑十法
- `/math/break-ten`：破十法

通用页面结构：

- 左侧：参数面板、生成按钮、多页数量、打印按钮
- 右侧：按 A4 样式渲染的预览页容器

## 3. 技术方案

技术栈：`Vue 3 + Vite + TypeScript + Pinia + Vue Router`

模块边界：

- `stores/worksheet.ts`：页面参数、题目数据、页数等状态
- `composables/generators.ts`：规则出题算法（加减法、凑十、破十）
- `components/control-panel.vue`：左侧参数输入与操作
- `components/print-preview.vue`：右侧多页预览
- `components/page-sheet.vue`：单页渲染（A4）

## 4. 数据流

1. 用户在左侧设置参数（行数、列数、页数、数值范围等）。
2. 点击“生成题目”后，调用规则出题函数。
3. 生成结果写入 Pinia（按页组织）。
4. 右侧根据 store 实时渲染多页。
5. 点击“一键打印”时仅打印预览区域（通过打印样式控制）。

## 5. 打印与样式策略

- 使用 `window.print()`。
- 通过 `@media print` 隐藏左侧控制区，仅保留右侧页内容。
- 每页使用 `page-break-after: always` 确保分页稳定。
- 页面尺寸按 A4 比例实现，优先保证打印内容边界不溢出。

## 6. 错误处理

- 参数越界时前端即时校验并阻止生成。
- 当页数过大时提示性能风险（例如超过 30 页）。
- 当题量为 0 时不触发打印。

## 7. 验收标准

- 能从模板列表进入 3 个数学模板页。
- 每个模板都能按参数生成至少 1 页题目。
- 支持同参数连续生成 N 页。
- 点击打印后可一次打印全部预览页。
- 页面可在桌面端稳定使用（Chrome/Edge）。
