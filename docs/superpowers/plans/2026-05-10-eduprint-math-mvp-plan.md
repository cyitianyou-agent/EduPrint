# EduPrint 数学打印制作 MVP 实施计划

## 步骤 1：工程初始化

- 创建 `Vue 3 + Vite + TypeScript + Pinia + Router` 基础结构
- 配置基础脚本与类型声明

## 步骤 2：路由与页面骨架

- 新增数学模板列表页
- 新增 3 个模板制作页骨架
- 建立从列表页到制作页的路由跳转

## 步骤 3：规则出题核心

- 实现通用计算题生成器
- 实现凑十法题生成器
- 实现破十法题生成器
- 支持按页批量生成

## 步骤 4：状态与交互

- 使用 Pinia 管理配置参数、页面数据与题目集
- 左侧参数面板联动生成逻辑
- 统一打印触发入口

## 步骤 5：打印预览与样式

- 实现 A4 单页组件与多页容器
- 配置 `@media print` 打印样式
- 确保多页连续打印

## 步骤 6：验证与收尾

- 构建校验（`npm run build`）
- 手动检查多页生成与打印入口
- 输出改动说明
